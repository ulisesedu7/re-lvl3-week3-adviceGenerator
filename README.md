
# Advice Generator — Day 1 Checkpoint

This branch contains the first classroom checkpoint for the Frontend Mentor Advice Generator project.

## What is implemented

- Vite + React with JavaScript and JSX.
- `App`, `AdviceCard`, and `AdviceButton` components.
- Local sample data controlled with `useState`.
- Responsive SCSS partials using BEM class names.
  - Investigate if you don't remember about BEM
- Semantic markup, keyboard focus, and reduced-motion support.

## Run the checkpoint

```bash
npm install
npm run dev
```

Validation commands:

```bash
npm run lint
npm run build
npm run preview
```
